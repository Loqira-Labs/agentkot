# Tools

Мета-инструмент, который управляет живым набором инструментов агента в текущей сессии: добавляет, удаляет, показывает, ищет, инспектирует и вызывает инструменты. Это единственная поверхность, через которую агент расширяет или урезает собственный набор возможностей во время работы.

## Операции

Инструмент различает операции полем `operation`. Допустимые значения: `add`, `remove`, `list`, `search`, `inspect`, `invoke`.

### add

Добавляет в живую сессию инструменты, которые производит заранее зарегистрированная возможность (capability) по переданной конфигурации. В релизном билде доступна ровно одна возможность — `cli-wrapper`.

| параметр | тип | обязателен | по умолчанию | смысл |
|---|---|---|---|---|
| `operation` | string | да | — | значение `"add"` |
| `capability` | string | да | — | имя возможности; единственное допустимое значение в билде — `"cli-wrapper"` |
| `config` | объект/значение | да для `cli-wrapper` | — | конфигурация возможности; либо инлайн-объект, либо `{"config_path": "<путь>"}` для загрузки из файла. Для `cli-wrapper` обязателен и должен содержать как минимум `name`, `script` и `commands` |
| `activate` | string | нет | `"immediate"` | когда инструменты становятся вызываемыми: `"immediate"` (в текущем ходу) или `"deferred"` (в следующем ходу) |

`config_path` разрешается относительно рабочего каталога сессии: путь нормализуется (раскрывается `~`, приводятся разделители, сворачиваются `.` и `..`), относительный путь присоединяется к каталогу сессии. Файл читается и парсится как JSON. Прочие ключи рядом с `config_path` накладываются поверх загруженного объекта — инлайн-значения имеют приоритет.

Возвращает: список канонических имён добавленных инструментов (`added`), новый номер эпохи набора (`epoch`), флаг `immediate`, список стартующих резидентов (`pending`), список ошибок активации (`activation_failed`), идентификатор события (`event_id`), флаги `metadata_pending` и `delivery_pending`.

Ошибки: неизвестная возможность возвращает ошибку `unknown capability '<имя>'; available: [...]` со списком доступных; невалидная конфигурация — `invalid config for capability '<имя>': <причина>`; возможность, не породившая ни одного инструмента, — `capability '<имя>' produced no tools`; конфликт имени/псевдонима внутри пакета или с уже существующим инструментом — отдельная ошибка. Инструмент провайдерного сервера динамически установить нельзя.

### remove

Убирает инструмент из живого набора по имени. Вступает в силу на следующем снимке набора.

| параметр | тип | обязателен | по умолчанию | смысл |
|---|---|---|---|---|
| `operation` | string | да | — | значение `"remove"` |
| `name` | string | да | — | каноническое имя удаляемого инструмента |

Возвращает: имя (`name`), флаг `was_present` (false, когда имени не было в наборе — идемпотентная операция без ошибки), `event_id`, `metadata_pending`, `delivery_pending`, список `deactivation_failed`, новый `epoch`.

Ядерные инструменты `Tools` и `Agent` удалить нельзя — попытка возвращает ошибку. Отсутствующее имя — не ошибка, а результат с `was_present: false`. Динамически добавленный инструмент возвращается повторным `add` с той же возможностью и конфигурацией; для встроенного инструмента операции восстановления нет.

### list

Показывает живой набор инструментов, опционально с разницей относительно указанной эпохи.

| параметр | тип | обязателен | по умолчанию | смысл |
|---|---|---|---|---|
| `operation` | string | да | — | значение `"list"` |
| `since_epoch` | integer/string | нет | отсутствует | если задан, возвращается ещё и `delta` — что изменилось с этой эпохи; `0` = «с самой первой мутации» |
| `kind` | string | нет | отсутствует | фильтр по виду инструмента (например `"builtin"`, `"mcp"`), либо по метке источника (например `"base"`, `"agent"`, `"mcp:<сервер>"`), либо по режиму вызова (`"direct"`, `"via_tools"`); сравнение без учёта регистра |

Возвращает: `epoch`, список `tools` (по каждому: `name`, `aliases`, `kind`, `source`, `call_mode`, `availability`, `interface_digest`, `decorated`, `deferred`) и, только при заданном `since_epoch`, поле `delta`.

Неузнанное значение `kind` даёт пустой список инструментов, не ошибку.

### search

Раскрывает отложенные инструменты — те, что в подсказке присутствуют только именем, а полную схему отдают по запросу.

| параметр | тип | обязателен | по умолчанию | смысл |
|---|---|---|---|---|
| `operation` | string | да | — | значение `"search"` |
| `query` | string | да | — | `select:<имя1>,<имя2>` для прямого раскрытия по точным именам, либо ключевые слова; префикс `+` перед словом делает его обязательным |
| `max_results` | integer/string | нет | `5` | максимум результатов по ключевым словам; на пути `select:` игнорируется |

Возвращает: `matches` (список имён), `query` (эхо запроса), `total_deferred_tools` (сколько всего отложенных инструментов в пуле), `pending_mcp_servers` (только при нулевом результате).

Поиск по ключевым словам имеет быстрые пути: точное совпадение имени (без учёта регистра) и префикс `mcp__`. Обязательные слова (`+слово`) отсеивают несовпадающие инструменты; далее инструменты ранжируются по совпадению в частях имени, описании и подсказке и возвращаются по убыванию релевантности в количестве не более `max_results`.

### inspect

Возвращает полное описание интерфейса инструмента вместе с его доступностью в текущем наборе.

| параметр | тип | обязателен | по умолчанию | смысл |
|---|---|---|---|---|
| `operation` | string | да | — | значение `"inspect"` |
| `name` | string | да | — | каноническое имя или псевдоним |

Возвращает: `requested_name`, `descriptor` (полный интерфейс), `availability`, `epoch`, `reason` (пояснение при недоступности, ограничено 2048 символами).

Пустое имя — ошибка `Tools{inspect}.name must not be blank`; несуществующий инструмент — ошибка `tool binding not found: <имя>`.

### invoke

Вызывает инструмент по имени. Вход передаётся целевому инструменту как есть, без разбора на стороне `Tools`.

| параметр | тип | обязателен | по умолчанию | смысл |
|---|---|---|---|---|
| `operation` | string | да | — | значение `"invoke"` |
| `name` | string | да | — | каноническое имя или псевдоним цели |
| `input` | значение | да | — | вход целевого инструмента |

Операция перехватывается до тела инструмента и маршрутизируется на целевой инструмент; достижение тела обёртки с этой операцией — ошибка.

## Поведение и ограничения

- Инструмент `Tools` присутствует всегда и не может быть удалён; вместе с `Agent` он относится к ядерным инструментам, удаление которых запрещено.
- `Tools` не может вызвать сам себя через `invoke`.
- Добавленный инструмент не появляется отдельной функцией в интерфейсе вызова инструментов модели. Его интерфейс получают через `Tools{inspect}`, а вызовы выполняют через `Tools{invoke}`. Разрешение «прямой вызов против `via_tools`» для каждого инструмента происходит один раз.
- Повторное добавление (`add`) разрешено только при полном совпадении источника и цифрового отпечатка интерфейса. Изменённое содержимое (другой отпечаток) требует другого имени — иначе ошибка конфликта.
- `activate: immediate` (значение по умолчанию) делает добавленные инструменты вызываемыми в текущем ходу; `activate: deferred` переносит вызов на следующий ход и сохраняет тёплый кэш подсказки.
- Для инструмента с резидентом, который ещё стартует, `add` возвращает запись `pending` с именем, ориентировочным временем готовности (`hint_ms`) и путём к журналу резидента; вызов до готовности возвращает отказ, а не ошибку.
- Максимальный размер результата инструмента — 100 000 символов; практический предел достигается только у `search` при раскрытии нескольких инструментов.
- Операция `search` работает только при включённом режиме отложенных инструментов. Режим включает переменная окружения `ENABLE_TOOL_SEARCH` (истинное значение либо `auto`/`auto:N`), а переменная `KOT_DISABLE_EXPERIMENTAL_BETAS` с истинным значением выключает его принудительно. При выключенном режиме операция возвращает ошибку.
- Каждая мутация набора (add/remove) увеличивает номер эпохи; `list` возвращает текущую эпоху, `since_epoch` позволяет получить разницу относительно прошлого состояния.

## Примеры

Добавить возможность `cli-wrapper` с инлайн-конфигурацией:

```json
{
  "operation": "add",
  "capability": "cli-wrapper",
  "config": {
    "name": "Git",
    "description": "состояние и история репозитория",
    "script": "git",
    "read_only": true,
    "commands": {
      "status": {
        "description": "состояние рабочего дерева",
        "params": [{ "name": "short", "type": "boolean", "style": "flag", "flag": "short" }],
        "required": []
      }
    }
  }
}
```

Добавить возможность `cli-wrapper`, загрузив конфигурацию из файла:

```json
{
  "operation": "add",
  "capability": "cli-wrapper",
  "config": { "config_path": "tools/git-tool.json" }
}
```

Показать встроенные инструменты живого набора:

```json
{ "operation": "list", "kind": "builtin" }
```

Раскрыть отложенные инструменты по именам, затем по ключевым словам:

```json
{ "operation": "search", "query": "select:Git" }
```

```json
{ "operation": "search", "query": "+git история", "max_results": 3 }
```

Получить интерфейс добавленного инструмента, затем вызвать его:

```json
{ "operation": "inspect", "name": "Git" }
```

```json
{ "operation": "invoke", "name": "Git", "input": { "operation": "status", "short": true } }
```
