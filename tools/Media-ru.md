# Media

Инструмент генерации медиа через настроенные провайдеры по единому, независимому от провайдера интерфейсу. Создаёт изображения, видео и аудио (музыку или синтез речи — по виду модели).

## Операции

Инструмент различает операции полем `operation`. Допустимые значения: `generate_image`, `generate_video`, `generate_audio`.

Общие для всех операций параметры:

| параметр | тип | обязателен | по умолчанию | смысл |
|---|---|---|---|---|
| `operation` | string | да | — | одна из трёх операций |
| `model` | string | да | — | точный идентификатор медиа-модели, без изменений |
| `provider` | string | нет | отсутствует | точное имя зарегистрированного провайдера; опускается, только когда идентификатор модели уникален среди провайдеров |
| `prompt` | string | да | — | текст задания; для синтеза речи — произносимый текст |
| `save_to` | string | зависит от операции | — | путь к выходному файлу или каталогу; обязателен для видео и аудио, необязателен для изображений |

Медиа-модели и их вид обнаруживаются через `Agent{list_models}`: медиа — это карточки с `for_chat: false` и указанным видом (image/video/audio). Имена провайдеров — через `Agent{list_providers}`.

### generate_image

Генерирует картинки, включая обусловленную оригинальными референсами генерацию/правку той же операцией.

| параметр | тип | обязателен | по умолчанию | смысл |
|---|---|---|---|---|
| `n` | integer | нет | 1 при поддержке или без объявления | положительная подсказка количества |
| `size` | string | нет | 1024x1024 при поддержке или без объявления | подсказка размера |
| `format` | string | нет | png при поддержке или без объявления | png или jpeg |
| `quality` | string | нет | отсутствует | подсказка качества |
| `style` | string | нет | отсутствует | подсказка стиля |
| `negative_prompt` | string | нет | отсутствует | чего избегать |
| `seed` | integer | нет | отсутствует | детерминированный seed |
| `background` | string | нет | отсутствует | transparent, opaque или auto |
| `images` | array | нет | пустой | оригинальные входы: source и обязательный media_type |
| `mask` | объект | нет | отсутствует | оригинальная маска; требует минимум одну картинку |

`Agent{list_models}` публикует `image.options`. Неподдерживаемая объявлением подсказка не отправляется и попадает в `ignored` только при явной передаче; неподдерживаемые images/mask дают typed unsupported до генерации. Без объявления решает адаптер. Оригиналы не нормализуются для vision; LocalPath разрешается от cwd, URL скачивается без ключей провайдера, объявленный MIME сверяется с байтами.

Подписочный image-id публикуется openai и openai-codex: при неоднозначности укажите provider. Обе identity идут в один Codex Images backend. Объявлены background и images; сервер подписки задаёт один PNG и остальные параметры. Direct OpenAI image-строки требуют API-ключ.

Возвращает saved (path, bytes, mime), usage, request_id, revised_prompt и непустой ignored. Без save_to картинки возвращаются inline-блоками.

### generate_video

Генерирует, редактирует и продлевает видео.

| параметр | тип | обязателен | по умолчанию | смысл |
|---|---|---|---|---|
| `save_to` | string | да | — | выходной файл или каталог |
| `task` | string | нет | `"auto"` | `auto`, `text_to_video`, `image_to_video`, `reference_to_video`, `edit`, `extend` |
| `images` | array | нет | пустой | 1–2 кадра image-to-video (first+last) или референсы стиля/объекта |
| `input_video` | объект | нет | отсутствует | исходное видео для редактирования или продления |
| `continuation_id` | string | нет | отсутствует | продолжить предыдущий stateful-результат |
| `stateful` | boolean | нет | `false` | сохранить новый результат на стороне сервера |
| `duration_seconds` | number | нет | `5.0` при поддержке или без объявления | конечная положительная подсказка длительности |
| `aspect_ratio` | string | нет | отсутствует | подсказка соотношения сторон |
| `resolution` | string | нет | отсутствует | подсказка разрешения, при поддержке передаётся без изменений |
| `fps` | integer | нет | отсутствует | подсказка кадров в секунду, минимум 1 |
| `seed` | integer | нет | отсутствует | подсказка детерминированного результата |

Каждое изображение и входное видео требуют `source` (источник с меткой вида) и `media_type`.

`Agent{list_models}` публикует объявленные моделью `video.tasks` и `video.options`. Неподдерживаемая объявлением подсказка не отправляется, её имя возвращается в `ignored`; неподдерживаемая задача или `continuation_id` даёт typed `unsupported` до генерации. Если объявления видео нет, поддержку судит адаптер. Незаданная длительность не отправляется без поддержки `duration`; неподдерживаемый `stateful` включается в `ignored` только при `true`.

Возвращает `saved`, необязательный `continuation_id` и непустой `ignored`, когда подсказки отфильтрованы.

Форма задачи: `text_to_video` не принимает медиа-входы; `image_to_video` принимает 1–2 изображения без видео/continuation; `reference_to_video` — минимум одно изображение без видео/continuation. `edit` требует ровно одно из исходного видео или continuation; `extend` требует исходное видео без continuation. Референсы допустимы при редактировании/продлении. `auto` запрещает одновременные видео и continuation, передаётся без изменений и при объявленной поддержке требует хотя бы одну совместимую со входами задачу.

### generate_audio

Создаёт музыку или синтезирует речь — маршрут выбирается по виду модели.

| параметр | тип | обязателен | по умолчанию | смысл |
|---|---|---|---|---|
| `save_to` | string | да | — | путь к выходному файлу или каталогу |
| `duration_seconds` | integer | нет | отсутствует | подсказка длительности в целых секундах, минимум 1; только для музыкальных моделей |
| `voice` | string | нет | отсутствует | идентификатор голоса; обязателен для моделей синтеза речи |
| `speed` | number | нет | отсутствует | скорость речи; конечная и положительная |
| `format` | string | нет | `"wav"` для речи | формат аудио; для моделей синтеза речи |

Возвращает: `saved`, `usage`, `request_id` и, для музыки, `description`.

Для музыкальной модели (`AudioGeneration`) параметры `voice`, `speed` и `format` запрещены — их передача даёт ошибку. Для модели синтеза речи (`TextToSpeech`) параметр `voice` обязателен, а `duration_seconds` запрещён.

## Инструменты распознавания

Помимо генерации, есть два инструмента разового распознавания: `RecognizeImage` и `RecognizeAudio`. Каждый делает один LLM-вызов с минимальным промптом распознавания, без инструментов и с минимумом контекста: передаёте одну или несколько картинок (или аудиозаписей) плюс задачу — получаете прямой ответ. Используйте их, когда агенту нужно описать картинку, прочитать с неё текст, сравнить картинки или расшифровать/проанализировать аудио — не тратя основной контекст. Операции, преобразующие медиа (редактирование, конвертация, многошаговый анализ с другими инструментами), требуют полноценного субагента.

### RecognizeImage

| параметр | тип | обязателен | по умолчанию | смысл |
|---|---|---|---|---|
| `model` | string | да | — | точный идентификатор модели с входом-изображением и текстовым выходом |
| `provider` | string | нет | отсутствует | точное имя зарегистрированного провайдера; опускается, только когда идентификатор модели уникален |
| `prompt` | string | да | — | задача распознавания; ссылки на картинки — `image 1`, `image 2`, … в порядке прикрепления; язык ответа следует языку задачи |
| `images` | array | да | — | одна или несколько картинок; порядок задаёт метки `image N` |

Каждый элемент: `source` (источник медиа, таблица ниже), необязательный `media_type` (обязателен для источников `url` / file-id / `s3_uri` / `gcs_uri`; локальный файл или встроенный payload определяются автоматически), необязательный `detail` (`low` / `high` / `auto`).

Локальные картинки полностью валидируются и нормализуются по общей vision-политике: длинная сторона ограничена 2000 пикселями, чрезмерно вытянутая режется на плитки в нативном разрешении (каждая помечена `Image N (part M of K)`). Картинки по URL передаются провайдеру как есть.

### RecognizeAudio

| параметр | тип | обязателен | по умолчанию | смысл |
|---|---|---|---|---|
| `model` | string | да | — | точный идентификатор модели с входом-аудио и текстовым выходом |
| `provider` | string | нет | отсутствует | точное имя зарегистрированного провайдера |
| `prompt` | string | да | — | задача распознавания; ссылки на записи — `audio 1`, `audio 2`, … |
| `audio` | array | да | — | одна или несколько аудиозаписей |

Каждый элемент: `source`, необязательный `media_type` (обязателен для источников `base64` / `url` / file-id). Формат локального файла выводится из расширения (mp3/wav/flac/ogg/aac/aiff/opus/m4a), запись отправляется встроенной.

### Поведение распознавания

- Разрешение модели: требуется chat-модель с нужной входной модальностью (изображение или аудио) и текстовым выходом. Неподходящая модель даёт ошибку со списком подходящих; неизвестный идентификатор передаётся как есть только при явном `provider`. Кандидаты обнаруживаются через `Agent{list_models}`.
- Локальный файл читается через виртуальное файловое представление сессии: учитывается незасинхронизированная (staged) версия файла и staged-удаления.
- Результат — типизированная сводка: `answer` (текст модели), `usage`, `request_id`, а при провале — `error` с кодом (`abort`, `rate_limit`, `truncated`, `refusal`, `empty_response`, `incomplete_stream`, …). Частичный ответ и usage сохраняются при любом провале.
- Токены распознавания попадают в сессионный usage-леджер.

Пример — две картинки одним вызовом:

```json
{
  "model": "<vision-model-id>",
  "prompt": "Что изменилось между image 1 и image 2? Кратко.",
  "images": [
    { "source": { "kind": "local_path", "path": "before.png" } },
    { "source": { "kind": "local_path", "path": "after.png" } }
  ]
}
```

Расшифровка локальной записи:

```json
{
  "model": "<audio-input-model-id>",
  "provider": "gemini",
  "prompt": "Что сказано в этой записи? Кратко.",
  "audio": [
    { "source": { "kind": "local_path", "path": "note.wav" } }
  ]
}
```

## Поведение и ограничения

- Разрешение модели: при заданном `provider` неизвестное имя даёт ошибку со списком зарегистрированных провайдеров; не найденная ни у одного провайдера модель даёт ошибку со списком подходящих моделей; модель, встречающаяся у нескольких провайдеров, даёт ошибку с требованием указать `provider`; модель неподходящего вида даёт ошибку со списком подходящих моделей этого провайдера.
- Источники медиа (`source`) — объект с полем `kind` и полями по варианту:

| kind | поля | значение |
|---|---|---|
| `base64` | `data` | содержимое, закодированное base64 |
| `url` | `url` | адрес файла |
| `anthropic_file` | `id` | идентификатор файла на стороне Anthropic |
| `openai_file` | `id` | идентификатор файла на стороне OpenAI |
| `google_file` | `uri`, `mime_type` | ссылка на файл Google и его тип |
| `s3_uri` | `uri` | адрес объекта в S3 |
| `gcs_uri` | `uri` | адрес объекта в Google Cloud Storage |
| `local_path` | `path` | путь на диске; относительный путь резолвится от рабочего каталога сессии |
| `bytes` | `data`, `mime` | содержимое в base64 и его тип |
- Объявляемые типы изображений: `png`, `jpeg`, `gif`, `webp`, `heic`, `heif`, `avif`, `bmp`. Объявляемые типы видео: `mp4`, `mov`, `avi`, `mpeg`, `mpg`, `webm`, `flv`, `wmv`, `3gpp`. Форматы аудио: `mp3`, `wav`, `flac`, `ogg`, `aac`, `aiff`, `opus`, `pcm16`, `mp4audio`, `m4a`.
- `save_to` разрешается относительно рабочего каталога сессии. Каталог (или путь без расширения) получает сгенерированное имя вида `image-1.png`, `video-1.mp4`, `audio-1.wav`; при нескольких изображениях с явной основой имени добавляется индекс: `art-1.png`, `art-2.png`.
- Запись файла атомарна (с fsync), родительские каталоги создаются автоматически.
- Без `save_to` изображение возвращается встроенным. Бюджет встроенных изображений — 8 блоков на вызов; изображения сверх бюджета записываются на диск и возвращаются путями, никогда не отбрасываются. Встроенное изображение подаётся как есть при максимальной стороне не более 2000 пикселей; чрезмерно вытянутое режется на плитки в нативном разрешении, прочее ужимается под границу.
- Ограничения провайдера вне объявленных image/video-фильтров возвращаются типизированными ошибками. Классы ошибок провайдера в `error.code`: `unsupported`, `unauthorized`, `rate_limit`, `overloaded`, `context_overflow`, `invalid_request`, `http`, `provider_error`, `agent_loop`.
- Прерывание запроса возвращает ошибку `media generation interrupted`; результат вызова при этом не формируется, а файл, который успел записаться на диск, остаётся.
- Если медиа-провайдеры в текущей конфигурации не настроены, вызов возвращает ошибку о недоступности генерации медиа.

## Примеры

Создать одно изображение и сохранить в файл:

```json
{
  "operation": "generate_image",
  "model": "<image-model-id>",
  "prompt": "натюрморт в тёплом свете",
  "save_to": "art.png",
  "size": "1024x1024"
}
```

Создать два изображения встроенно, без сохранения на диск:

```json
{
  "operation": "generate_image",
  "model": "<image-model-id>",
  "prompt": "эскиз логотипа",
  "n": 2
}
```

Создать видео по тексту:

```json
{
  "operation": "generate_video",
  "model": "<video-model-id>",
  "prompt": "камера медленно облетает горный хребет на рассвете",
  "save_to": "clip.mp4",
  "duration_seconds": 5
}
```

Отредактировать существующее видео:

```json
{
  "operation": "generate_video",
  "model": "<video-edit-model-id>",
  "prompt": "заменить фон на ночной город",
  "save_to": "edited.mp4",
  "task": "edit",
  "input_video": { "source": { "kind": "local_path", "path": "input.mp4" }, "media_type": "mp4" }
}
```

Создать музыку и синтезировать речь:

```json
{
  "operation": "generate_audio",
  "model": "<music-model-id>",
  "prompt": "спокойная эмбиент-тема",
  "save_to": "track.wav",
  "duration_seconds": 30
}
```

```json
{
  "operation": "generate_audio",
  "model": "<tts-model-id>",
  "prompt": "Здравствуйте, это проверка синтеза речи.",
  "save_to": "speech.wav",
  "voice": "<voice-id>"
}
```
